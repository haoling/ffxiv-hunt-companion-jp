# M2 ゲーム内確認チェックリスト

M2（手入力＋ルート）の動作を、ゲームを遊びながら確認するためのリスト（[PLAN §11.1](../PLAN.md#111-プレイヤーによるゲーム内確認)）。結果は `OK` / `NG（気づいたこと）` を各項目に書き込む。すべて確認できるまで M2 は完了にしない。

## A. リセット時刻

- [x] **日次リセット**: デイリー手配書を受注し直せるようになる時刻が、日本時間 0:00（手配書画面の表示）と合っているか。
  - **結果: OK**（日本時間 0:00 で合っている）
- [x] **週次リセット**: エリート手配書（リスキーモブ）を受注し直せるようになる時刻が、日本時間の火曜 17:00 と合っているか。
  - **結果: OK**（火曜 17:00 JST で合っている）
- **補足（プレイヤーの確認）**: 受注済みの手配書はリセットを過ぎても消えず、倒せば報酬ももらえる。リセットは次の受注が可能になる時刻なので、アプリも行を自動では消さない。

## B. テレポ優先

- [x] 手配書 2〜3 枚ぶんの対象を手入力し、出発地を選んで「テレポ優先」のルートを出す。案内どおりに「テレポ: ○○」のエーテライトへ飛ぶと、そのエリアに着けるか。
- [x] 案内された地域名（例:「サゴリー砂漠」）で、実際にそのモブが見つかるか。方角（北東へ など）は大きくずれていないか。
- [x] ツインプールズ（クルザス西部高地）のような広い地域で、表示された中心座標「(x, y) 付近」にそのモブがいるか。広い地域でも探しやすくなったか。
- [x] 湧き位置が複数あるモブ（「ほかの湧き位置」が出るもの）で、最初に案内された座標（実測点が最も多い所）に実際にいるか。
- [x] 湧き位置の実測がないモブ（座標が出ない）は、従来どおり地域名と方角で探せるか。
- [x] 隣のエリアを「移動」と案内されたとき、案内された出口（座標つき）から本当に行けるか。

- **結果: OK**（B の項目すべて、ゲーム内で問題なく確認できた）
