# M2 ゲーム内確認チェックリスト

M2（手入力＋ルート）の動作を、ゲームを遊びながら確認するためのリスト（[PLAN §11.1](../PLAN.md#111-プレイヤーによるゲーム内確認)）。結果は `OK` / `NG（気づいたこと）` を各項目に書き込む。すべて確認できるまで M2 は完了にしない。

## A. リセット時刻

- [x] **日次リセット**: デイリー手配書を受注し直せるようになる時刻が、日本時間 0:00（手配書画面の表示）と合っているか。
  - **結果: OK**（日本時間 0:00 で合っている）
- [x] **週次リセット**: エリート手配書（リスキーモブ）を受注し直せるようになる時刻が、日本時間の火曜 17:00 と合っているか。
  - **結果: OK**（火曜 17:00 JST で合っている）
- **補足（プレイヤーの確認）**: 受注済みの手配書はリセットを過ぎても消えず、倒せば報酬ももらえる。リセットは次の受注が可能になる時刻なので、アプリも行を自動では消さない。

## B. テレポ優先

- [ ] 手配書 2〜3 枚ぶんの対象を手入力し、出発地を選んで「テレポ優先」のルートを出す。案内どおりに「テレポ: ○○」のエーテライトへ飛ぶと、そのエリアに着けるか。
- [ ] 案内された地域名（例:「サゴリー砂漠」）で、実際にそのモブが見つかるか。方角（北東へ など）は大きくずれていないか。
- [ ] 隣のエリアを「移動」と案内されたとき、案内された出口（座標つき）から本当に行けるか。

## C. 飛行移動

- [ ] 設定を「飛行移動」にして、複数のエリアにまたがる対象でルートを出す。通過するエリアと出口のとおりに、テレポせずに行けるか。
- [ ] 遠回りすぎないか（明らかに近道があるのに使っていない、など）。

## D. 徒歩移動

- [ ] 設定を「徒歩移動」にして同じ対象でルートを出す。地上だけで行けるか（飛行が必要な区間は通らず、その先はテレポになっているか）。
- [ ] クルザス西部高地 ↔ アバラシア雲海をまたぐ対象を入れたとき、徒歩ではそこを通らずテレポになるか。

## E. 操作

- [ ] スマホで、手入力→ルート確認→チェックまでの操作に困るところはないか（文字の大きさ、押しやすさ）。
- [ ] ブラウザを閉じて開き直しても、手配書の行とチェック・設定が残っているか。
