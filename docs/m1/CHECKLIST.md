## B. 飛行しないと通れない出口

`scripts/zone-links.overrides.json` の `requiresFlying`（推測で入れたもの）を確かめる。飛行マウントで行ける状態で、地上マウントだけで通れるかを試す。

- [ ] クルザス西部高地 → アバラシア雲海: 地上だけで行けない（飛行が必要）か。行けるなら `requiresFlying` から外す
- [ ] アバラシア雲海 → クルザス西部高地: 同じく、地上だけで戻れない（飛行が必要）か
- [ ] 高地ドラヴァニア → ドラヴァニア雲海: 地上だけで行けない（飛行が必要）か
- [ ] ドラヴァニア雲海 → 高地ドラヴァニア: 同じく、地上だけで戻れない（飛行が必要）か

次の出口は、補正リストに載せていないが気になるところ。地上だけで通れるかを見て、飛行が必要なら教えてほしい（`requiresFlying` に足す）。

- [ ] 低地ドラヴァニア ↔ イディルシャイア（地上で歩いて行けるか）
- [ ] クルザス中央高地 ↔ イシュガルド：下層、クルザス西部高地 ↔ イシュガルド：下層（地上で入れるか）
- [ ] 紅玉海 ↔ クガネ、ギラバニア湖畔地帯 → ギラバニア山岳地帯（地上で通れるか）
