# M1 ゲーム内確認チェックリスト

[PLAN §11.1](../PLAN.md#111-プレイヤーによるゲーム内確認) に沿った、M1（データ生成）のゲーム内確認項目。
データは `public/data/hunts.json`。中身の見方は [REPORT.md](./REPORT.md) を参照。結果は各項目の末尾に OK／NG と気づいたことを書き足す。

## A. 手配書の表記と `hunts.json` の一致（任意）

手配書の対象は毎回変わるので、特定のモブを探しに行く確認はしない。モブ名・討伐体数・生息場所はゲームデータをそのまま引いていて、M0 でも照合済みなので、必須にはしない。
ふだんの手配書を受け取ったついでに、気になったときだけ次を見る（件数は 1〜2 件で十分）。

- [ ] 手元の手配書の 1〜2 件について、「討伐対象」「討伐体数」「生息場所」が `public/data/hunts.json` の中身と同じか（`targets` の `name` / `neededKills`、`regions` の `name`）。違ったら、モブ名・手配書の種類（拡張・級）と一緒に教えてほしい

## B. 飛行しないと通れない出口

`scripts/zone-links.overrides.json` の `requiresFlying`（推測で入れたもの）を確かめる。飛行マウントで行ける状態で、地上マウントだけで通れるかを試す。

- [x] クルザス西部高地 → アバラシア雲海: 地上だけで行けない（飛行が必要）か。行けるなら `requiresFlying` から外す → OK: 飛行が必要（PR のコメントで確認）
- [x] アバラシア雲海 → クルザス西部高地: 同じく、地上だけで戻れない（飛行が必要）か → OK: 飛行が必要（出口のある島まで地面がつながっていない）
- [x] 高地ドラヴァニア → ドラヴァニア雲海: 地上だけで行けない（飛行が必要）か → NG: 飛行は必要ない（地上で行ける）。`requiresFlying` から外した
- [x] ドラヴァニア雲海 → 高地ドラヴァニア: 同じく、地上だけで戻れない（飛行が必要）か → NG: 飛行は必要ない（地上で戻れる）。`requiresFlying` から外した

次の出口は、補正リストに載せていないが気になるところ。地上だけで通れるかを見て、飛行が必要なら教えてほしい（`requiresFlying` に足す）。

- [x] 低地ドラヴァニア ↔ イディルシャイア（地上で歩いて行けるか） → OK: 地上で行ける（現状のまま）
- [x] クルザス中央高地 ↔ イシュガルド：下層（地上で入れるか） → OK: 地上で行ける。出入りは門番（GATEKEEPER）を経由する（現状のまま）
- [x] クルザス西部高地 ↔ イシュガルド：下層（地上で入れるか） → OK: 徒歩で出入りできる（現状のまま）
- [x] 紅玉海 ↔ クガネ（地上で通れるか） → OK: 徒歩で出入りできる（現状のまま）
- [x] ギラバニア湖畔地帯 → ギラバニア山岳地帯（地上で通れるか） → OK: 徒歩で出入りできる（現状のまま）
