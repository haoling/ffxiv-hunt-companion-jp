# M3 ゲーム内確認チェックリスト

実機・実際の手配書で OCR の精度を確かめるためのチェックリストです。サンプル画像はご自身の手元で用意し、**リポジトリにはコミットしないでください**。結果は各項目の `[ ]` を `[x]`（OK）／`[NG]` にして、気づいたことを書き足してください。

## 準備

- [ ] 手配書（デイリー）を受け取り、**スクリーンショット**を撮る。1 ページずつ、合計 30 枚以上（複数の拡張・複数の手配書で）。UI サイズや画面の明るさを変えたものも混ぜる。
- [ ] 同じ手配書の画面を、**スマホのカメラで撮った写真**を 30 枚以上用意する（斜めから・反射がある・暗めなど、撮影条件を変えたものも混ぜる）。

## A. スクリーンショットの読み取り（目標: 上位 1 件の正解率 95% 以上）

- [ ] 「スキャン」タブで「スクリーンショット・画像を選ぶ」から 1 枚を選ぶ。→ 範囲の調整画面が出る。
- [ ] 下部パネル（討伐対象・討伐体数・生息場所の部分）を指でなぞって囲み、「読み取る」を押す。→ 初回は読み込みに時間がかかる旨の表示が出て、認識結果が出る。
- [ ] 「討伐対象」「討伐体数」「生息場所」の読み取り結果が、画面の表示と合っている。
- [ ] 候補の 1 件目が、手配書の「討伐対象」のモブである（件数を数える: ___ / ___ 枚）。
- [ ] 同じ名前のモブが複数ある場合（例: スノウウルフ）、「生息場所」が一致した候補が上に出る。
- [ ] 「追加して次へ」で手配書タブに追加され、討伐体数が手配書と同じ。

## B. スマホ撮影の読み取り（目標: 上位 3 件の正解率 90% 以上）

- [ ] 「カメラで撮影」でカメラが起動し、ガイド枠に下部パネルを合わせて撮影できる。
- [ ] 撮影した写真で「読み取る」を押し、候補の 3 件以内に正しいモブが入っている（件数: ___ / ___ 枚）。
- [ ] 斜め・暗め・反射があるときの結果（読めた／読めなかった）を書き留める: ___
- [ ] 読めなかったとき、警告が出て、手配書タブの手入力に進める。

## C. 条件を変えたとき

- [ ] ゲームの UI サイズ（小・中・大）を変えたスクリーンショットでも読み取れる: ___
- [ ] 画面の明るさを変えたスクリーンショット／写真でも読み取れる: ___
- [ ] 手配書のページを 1/5 から順に読み取り、足りないページがあると「まだ読み取っていないページ」が出る。

## D. 全体

- [ ] 一度読み取った後、「別のページ・画像を読み取る」で続けて読み取れる（2 回目以降は速い）。
- [ ] 読み取ったモブを追加したあと、ルートタブで文字のルートが出る。
